# 🚀 To-Do List Interativa

Uma aplicação web minimalista e responsiva para gerenciar suas tarefas diárias. Desenvolvida com HTML, CSS e JavaScript puro, esta To-Do List permite criar, acompanhar e organizar suas atividades de forma eficiente.

---

## ✨ Recursos

* **Gerenciamento Completo de Tarefas (CRUD):**
    * **Criar:** Adicione novas tarefas com descrição, data e hora opcionais.
    * **Filtrar:** Visualize tarefas por status: Todas, Em Andamento, Concluídas e Ignoradas.
    * **Concluir:** Marque tarefas como concluídas, retirando a opção de "ignorar".
    * **Atualizar:** Edite a descrição de tarefas existentes.
    * **Deletar:** Remova tarefas permanentemente, com uma modal de confirmação para evitar exclusões acidentais.
* **Status de Tarefas:** Classifique suas tarefas como `Em Andamento`, `Concluídas` ou `Ignoradas`.
* **Organização por Data e Hora:** Defina datas e horários específicos para suas tarefas.
* **Persistência de Dados:** Suas tarefas são salvas automaticamente no `localStorage` do navegador, mantendo-as seguras mesmo após fechar a aplicação.
* **Interface Intuitiva:**
    * **Ícones Modernos:** Utiliza a biblioteca Font Awesome para uma experiência visual agradável.
    * **Animações Suaves:** Transições fluidas ao adicionar, remover e atualizar tarefas, além de um modo escuro elegante.
    * **Estilo Minimalista:** Design limpo e focado na usabilidade.
    * **Modo Escuro:** Alterna entre temas claro e escuro para conforto visual em diferentes ambientes.
* **Responsividade Total:** Adapta-se perfeitamente a diferentes tamanhos de tela (desktops, tablets e celulares), incluindo um menu lateral (`sidebar`) para navegação em dispositivos móveis.
* **Tratamento de Erros:** Validação básica para evitar tarefas vazias.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da aplicação.
* **CSS3:** Estilização, responsividade e animações.
    * **Cores:** `#f3e2d4`, `#c5b0cd`, `#415e72`, `#17313e` (adaptadas para modo claro e escuro).
* **JavaScript (ES6+):** Lógica de negócios, manipulação do DOM e gerenciamento de estado.
* **Font Awesome:** Biblioteca de ícones (versão 6.5.2).

## ⚙️ Como Rodar o Projeto

É muito simples! Este projeto é puramente front-end e não requer nenhuma configuração de servidor.

1.  **Clone o Repositório (ou baixe os arquivos):**
    ```bash
    git clone [LINK_DO_SEU_REPOSITORIO]
    cd todo-list-project
    ```
    *(Substitua `[LINK_DO_SEU_REPOSITORIO]` pelo link do seu repositório GitHub, caso você o envie para lá).*

2.  **Abra o arquivo `index.html`:**
    * Localize o arquivo `index.html` na pasta do projeto.
    * Clique duas vezes nele ou arraste-o para o seu navegador (Chrome, Firefox, Edge, etc.).

E pronto! A aplicação estará rodando no seu navegador.
